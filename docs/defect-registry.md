# Defect registry

The defects found and closed while porting Pux 2.0.x-dev (upstream c9s/Pux, commit 30bc692 of
2023-03-28) to PHP 8.2-8.5 as PuxDZ 3.0.0. The IDs are used in `CHANGES.md`, `UPGRADE-3.0.md`,
`docs/probes.md` and in the docblocks of the tests (`@see docs/defect-registry.md <ID>`).

- R: regressions of the 2023 "PHP 8.2 update" commits (upstream PR #110, #111).
- L: logic defects inherited from upstream or found during the port.
- P: incompatibilities with PHP 8.2-8.5.

Columns: "Location" is the file and method at 30bc692 (or where the defect was found); "Closing
test(s)" are the tests whose docblock names the ID (`<seam directory>/<class>::<method>`); "Commit"
is the commit whose title starts with the ID, or the commit named in the cell when the ID was
closed in a review commit without a test of its own; "Upstream issue" is the issue or pull
request number in c9s/Pux. The check of this table against the tests and the history is
`docs/reconciliation-3.0.md`.
